OpenICC-native ChArUco board — print instructions

  • Paper: A3 landscape. Scale: 100% / Actual size (no "fit to page").
  • Verify after printing: one checker square must measure 40.0 mm with a ruler. If it doesn't, fix the print scale — do not "compensate" in software.
  • Mount flat and rigid (foam board / aluminium composite). Any bend ruins calibration.
  • Spec: 10×7 squares · square 40 mm · marker 20 mm (= ½·square, OpenICC's stock ratio) · dictionary DICT_ARUCO_ORIGINAL · marker ids 0–34.
