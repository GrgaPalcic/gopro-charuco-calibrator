How to calibrate a camera

  1. Choose the camera setup in step 1.
  2. Plug the GoPro in over USB and switch it on.
  3. Click Open preview, then Start new run.
  4. Move the board to each orange box until the guide is done.

Recording your data on the camera, for example for UMI? Choose From a recording in step 1 instead: a USB calibration is not valid for it.

  • Orange box: hold the board here next
  • Orange dot: put the board centre here
  • Green: done
  • Blue: still to do
  • Red dot: where the board is now
  • Dashed line: the board centre must reach it or beyond

            Camera
            
          
          
            From a recording: leave this as it is and the run is named after the camera's serial number, for example gopro13_1234, so each file maps to one camera.
            
          

          
            
            
            Lens and resolution define the calibrated model. Keep them identical to how your data is recorded.
            
            
            
              
              
            
            
          
            

          
            
            Frame size and device
            
            
              
            Frame size is the size frames are decoded at. Device and pixel format are used only when automatic GoPro setup is off.
